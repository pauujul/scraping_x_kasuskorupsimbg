# Scraping Komentar YouTube: Kasus Korupsi MBG
Tugas Sosial Media, Bisnis Digital UNM

Mengambil komentar publik YouTube tentang kasus korupsi MBG, lalu menghitung kata kunci yang sering muncul.

Cara menjalankan:
1. pip install -r requirements.txt
2. Isi URL video di scraper.py
3. python scraper.py
